# Refinement: image-Feld in LocalBusiness Schemas auf Container-Foto umstellen

## Hintergrund

Im vorherigen Pass wurde an allen Schema-image-Feldern das Logo (`android-chrome-512x512.png`) gesetzt — strikt nach Spec "überall identisch". Strategisch ist das suboptimal: Das `image`-Feld im LocalBusiness-Schema wird von Google für Knowledge Panel, Local Pack und Maps verwendet. Ein echtes Geschäftsobjekt-Foto wirkt dort stärker als ein Logo.

Saubere Trennung: 
- **Organization Schema** = Brand-Identity → Logo bleibt richtig
- **LocalBusiness Schema** = Geschäftsobjekt → Container-Foto
