# Fix: image-Feld im Service-Schema provider-Block ergänzen

## Hintergrund

Google Rich Results Test zeigt für `https://planexus.de/laborcontainer-basel` noch einen Hinweis:
> "Feld 'image' fehlt (optional)" — beim Organization-Objekt mit Adresse Emil-Mayer-Straße 1, Albstadt

Diese Organization ist **eingebettet als `provider` im Service-Schema** auf den City-Pages (Zeile ~13–34 in basel.astro). Sie wurde im letzten Pass nicht angefasst, weil dort nur LocalBusiness-Schemas behandelt wurden.

## Beispiel-Stelle (basel.astro)

Aktueller Code (Zeile ~13–22):
```astro
const serviceSchema = {
  "@context": "https://schema.org",
  "@type": "Service",
  "name": "Laborcontainer Basel",
  "provider": {
    "@type": "Organization",
    "name": "Planexus GmbH",
    "url": "https://planexus.de",
    "telephone": "+49 7435 7519 700",
    "email": "info@planexus.de",
    "address": { "@type": "PostalAddress", "streetAddress": "Emil-Mayer-Straße 1", "addressLocality": "Albstadt", "postalCode": "72461", "addressCountry": "DE" },
    "parentOrganization": { "@type": "Organization", "name": "Wesemann Holding GmbH" }
  },
  ...
};
```

## Aufgabe

Im `provider`-Block des Service-Schemas auf allen betroffenen Pages ein `image`-Feld ergänzen, direkt nach dem `name`-Feld:

```json
"image": "https://planexus.de/android-chrome-512x512.png"
```

**Begründung für Logo (nicht Container-Foto):** Der `provider` ist ein Organization-Type (Brand-Identity), kein LocalBusiness-Type. Konsistent zur bereits etablierten Trennung: Organization = Logo, LocalBusiness = Container-Foto.

### Grep-Verifikation der Stellen vorab

Bevor du die Änderungen durchführst, prüfe per grep, welche Dateien tatsächlich ein Service-Schema mit eingebettetem `provider: { "@type": "Organization", ... }` haben:

```bash
grep -rln '"provider".*"@type": "Organization"\|"provider": {' src/pages/
```

Falls einzelne der oben aufgeführten Pages kein solches Schema haben → nicht anfassen, im Bericht erwähnen.

Falls weitere Pages außerhalb der Liste betroffen sind → mit demselben Fix einbeziehen.

## Wichtig: NICHT anfassen

- LocalBusiness-Schemas (haben bereits image, sind grün im Test)
- Article-Schemas (Magazin) (haben bereits eigenes image-Feld)
- BreadcrumbList, FAQPage, AggregateOffer, etc.
- Service-Schemas, die KEIN provider-Organization-Objekt enthalten

## Akzeptanzkriterien

- [ ] In allen betroffenen Dateien hat der `provider`-Block des Service-Schemas ein `image`-Feld
- [ ] Wert ist überall identisch: `https://planexus.de/android-chrome-512x512.png`
- [ ] Build läuft fehlerfrei durch (`npm run build`)
- [ ] Auf einer Beispiel-City-Page (basel) liefert das HTML jetzt:
  - 2× `android-chrome-512x512.png` (Layout Organization + Service provider Organization)
  - 2× `labtogo-industrie.webp` (Layout LocalBusiness + City LocalBusiness)
