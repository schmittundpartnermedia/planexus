## Was zu tun ist

In jeder unten gelisteten Datei den **Service-Schema provider-Block** finden und ein `image`-Feld direkt nach dem `name`-Feld einfügen.

### Aktueller Zustand (Beispiel basel.astro)

```javascript
"provider": {
  "@type": "Organization",
  "name": "Planexus GmbH",
  "url": "https://www.planexus.de",
  "telephone": "+49 7435 7519 700",
  ...
}
```

### Gewünschter Zustand

```javascript
"provider": {
  "@type": "Organization",
  "name": "Planexus GmbH",
  "image": "https://www.planexus.de/android-chrome-512x512.png",
  "url": "https://www.planexus.de",
  "telephone": "+49 7435 7519 700",
  ...
}
```

**Formatierung:** `image`-Feld auf einer EIGENEN Zeile mit gleicher Einrückung wie `name`. KEIN Inline-Format wie `"name": "...", "image": "..."` auf einer Zeile.

## Verbindliche Verifikation pro Datei

Nach jedem str_replace auf eine Datei MUSS ausgeführt werden:

```bash
grep -A1 '"@type": "Organization"' [DATEINAME] | grep -c "android-chrome-512x512"
```

**Erwartung: mindestens 1 Treffer pro Datei.** Wenn 0, dann ist der Patch nicht angekommen — Datei nochmal anschauen, korrigieren.

## Globale Verifikation am Ende

Nach allen Edits AUSFÜHREN und Output IM BERICHT ZEIGEN:

```bash
echo "=== Pages mit image im provider-Block ===" && for f in src/pages/laborcontainer-*.astro src/pages/leistungen/*.astro src/pages/laborcontainer/*.astro src/pages/branchen/*.astro; do
  count=$(awk '/"provider"/,/^[[:space:]]*}[,]?$/' "$f" | grep -c "android-chrome-512x512")
  echo "$count $f"
done
```

Im Bericht zeigen: Welche Datei hat 0 Treffer, welche hat 1+? Erwartung: mindestens 1 für jede der 24 oben gelisteten Pages.
